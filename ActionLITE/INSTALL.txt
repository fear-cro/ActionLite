WoW Forever / Interface 16001

Installation
1. Extract the ActionLITE folder into Interface/AddOns. Replace the existing
   ActionLITE folder with the complete folder from this ZIP.
2. Keep the rotation and Media subfolders inside ActionLITE.
3. Keep your WTF folder and saved settings. Restart the game or run /reload.
4. Open the ActionLITE menu with /action or the minimap button.
5. Disable the old standalone CastTrail addon if installed; Cast Trail is
   now included in ActionLITE.

Rotation selection
Leveling Rotation is selected by default and uses the original finalized
leveling rotation for your class. The optional talent builds are separate.
Selecting a DPS or tank build unchecks the previous rotation. Unchecking a
talent build returns to Leveling Rotation. One rotation always stays selected.
Existing valid saved build choices and other preferences are retained.
Only learned, enabled spells are used. Configure spell icons in the Spells tab.
Burst abilities require Burst On. Area damage requires AoE On and the class's
configured enemy/resource thresholds. No consumables are added.

Display and Cast Trail
General > Display includes Hide Burst and AoE boxes (default off). Enabling
it replaces the labeled buttons with clickable red/off or green/on squares.
The small icon uses a fixed size and position. The redundant Burst status
line has been removed.
Cast Trail On and Lock Cast Trail are enabled by default. Initially the trail
aligns with the main icon's right edge, five pixels below. Unlock it to move
or resize it independently, then lock it to keep your chosen position.

Reporting an issue
Open Bug report > Open Debugger. Click Start outside combat, immediately
engage and reproduce the issue, then wait five seconds after combat ends.
Click Results, Select All and copy the complete report with your description.
Reports stay in memory until the next capture or logout; they are not sent
automatically. The recorder includes current settings and rotation state.
