# ActionLITE developer documentation

ActionLITE v1.1.7 supports learned-spell Leveling Rotation priorities, shared DPS/Heals/Tank role modes and protected focus-based healing for open-world parties and confirmed dungeon healers in WoW Forever.

- [Rotation development](Rotation-Development.md) explains class modules, settings, spell registration, HealingEngine providers and validation.
- The current addon source is in [`../ActionLITE/`](../ActionLITE/).
- Archived releases are in [`../older-versions/`](../older-versions/).

Keep implementation comments and documentation in English. Use the stable English spell name as the internal key; localization and the learned spellbook resolve the live client name and rank.
