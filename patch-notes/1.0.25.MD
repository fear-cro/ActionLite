# ActionLITE v1.0.25 Patch Notes

October 16, 2026

Updates the v1.0.23 level-60 build and carries forward its class builds, Leveling Rotation selections, UI, Cast Trail, and reporting features.

## Warrior

- Applied the Protection target-detection fix to **Leveling Rotation**. Hidden target-relationship information can no longer stop the rotation on Auto Attack.
- Applied the Rage-reserve fix to the Leveling rotation. Heroic Strike, Cleave, Slam, and Sweeping Strikes honor their configured thresholds even when Rage is hidden.
- Corrected Fury's optional Heroic Strike, Cleave, Slam, and Sweeping Strikes reserve checks so an unavailable resource display cannot bypass the user's sliders. Core attacks retain their spell-usability fallback.
- Keep icons, hotkeys, and action-bar glows aligned with the same resource threshold.
- Clarified DPS and Protection Rage controls. Existing 80-Rage DPS overflow protection is retained.

## Paladin and Feral Tank Druid

- Verified Protection Paladin's mana-slider boundaries and resource-gated icons.
- Verified Feral Tank Druid's Maul reserve, defensive resource thresholds, and protected target checks used by Growl.
- These tank rotations already handle the reported Warrior failure modes; no additional Paladin or Druid rotation changes were required.

## Version and installation

- The current addon version is now **1.0.25**.
- Install the repository's top-level `ActionLITE` folder, then reload the UI. Saved settings and rotation selections are retained.
- The separate beta package is **v0.25**, under `older-versions/ActionLITEv0.25/`. Its notes are in `older-versions/patch-notes/`.

For the preceding class, UI, and spell changes, see [1.0.23.MD](1.0.23.MD).
