# ActionLITE

World of Warcraft Forever rotation profiles and shared UI.

## Current build

Version **1.0.23**. The addon source is stored as individual files in `ActionLITE/`.

## Installation

Copy the `ActionLITE` folder into your game’s `Interface/AddOns/` directory, then restart the game or reload the UI. The resulting path should be `Interface/AddOns/ActionLITE/ActionLITE.toc`.

## Patch notes

See the [Word patch notes](ActionLITE-Patch-Notes-2026-10-15.docx) in the repository root.

## Updates

Commit source changes directly to this repository. Keep the addon folder named `ActionLITE`, including its capitalization. Keep Word patch notes in the repository root, outside the addon folder. Use Fear-Cro for first-party author credits.
